Nine environmental layers (10 x 10 m, ASCII grid format) from Papadopulos et al. (2013), used in `003_maxent.sh` and for extracting environmental values at occurrence points:

`aspect.asc`, `coastdist.asc`, `creekdist.asc`, `dem.asc`, `geology.asc` (categorical), `hillshade.asc`, `slope.asc`, `vegetation.asc` (categorical), `vrm.asc`
